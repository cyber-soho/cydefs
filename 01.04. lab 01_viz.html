The whole lab in three moves

Part 1 builds your safe sandbox, Part 2 draws and justifies the map, then one ZIP goes to the Omnivox Léa DropBox. Everything happens only inside your own isolated laboratory.

Step 1 — Download and install VirtualBox

Official site only: virtualbox.org — current 7.2.x line, default installer options. Optionally verify any link first with the VirusTotal URL scanner (Legal Notice §10).

1 Shown: VirtualBox 7.2.x (current, September 2026). Newer releases may change the download page and wizard visuals; the sequence — download, install with defaults, accept the network-driver prompt — stays the same. Mac M-series: prefer UTM or VMware Fusion and state it in your chapter (§ 5 of the lab document).

Step 2 — Create the isolated network NorthMaple-LAN

File ▸ Tools ▸ Network Manager ▸ NAT Networks ▸ Create. Name it exactly NorthMaple-LAN, prefix 10.10.0.0/24, DHCP (Dynamic Host Configuration Protocol) enabled. VMs talk to each other; nothing outside reaches in.

2 In VirtualBox 7.x the Network Manager lives under File ▸ Tools; in the old 6.x line it was under Preferences ▸ Network. A future release may move it again — the tool name stays “Network Manager”.

Step 3 — Create the two company machines

VM 1: NM-FILESRV — Ubuntu Server LTS, 2 GB RAM (Random Access Memory), 2 CPUs (Central Processing Units), 25 GB. VM 2: NM-WIN-WS1 — free Windows evaluation from the Microsoft Evaluation Center, 4 GB, 2 CPUs, 40 GB. Both attached to NorthMaple-LAN. Laboratory-only usernames and passwords — never your real ones.

3 Shown: Ubuntu 24.04.x LTS and a Windows 11 Enterprise evaluation (September 2026). Point-release numbers and the exact evaluation build on the Microsoft page change over time — take the current LTS/evaluation offered and note its version in your manual (N.2).

Step 4 — Prove it works, prove it is isolated

On the VMs: ip a / ipconfig, then a VM-to-VM ping that must answer. From your real computer: a ping to the VM that must fail — the failure is your isolation proof. Screenshot all three.

4 Windows may silently drop pings from the Linux VM — its firewall blocks ICMP (Internet Control Message Protocol) by default. That is normal; the Linux-side replies plus the failed host-ping are sufficient evidence.

Step 5 — Snapshot: your undo button

Machine ▸ Take Snapshot, named exactly LAB01-clean-install — or the CLI (Command-Line Interface): VBoxManage snapshot "NM-FILESRV" take "LAB01-clean-install". Repeat for both VMs. Every future lab starts from a snapshot.

Part 2, step A — Draw the map in diagrams.net

Free, no account: diagrams.net. Four zone rectangles (leave room for the Class-13 guest Wi-Fi zone), every system in its zone, every entry point marked, then export PNG (Portable Network Graphics) and keep the .drawio source.

5 diagrams.net updates its interface continuously; menus and shape panels may look different from any capture. Alternatives (state the substitution): Excalidraw, Mermaid Live Editor, LibreOffice Draw — full table in § 5 of the lab document.

Part 2, step B — Fill the zoning workbook until Self_Check says PASS

Open the provided LAB01_zoning_workbook.xlsx (Excel or free LibreOffice Calc). Yellow cells only: place the systems, write one allowed flow per row with its 1–2-sentence justification, state the trust levels. Submit only when the verdict reads “YES — all checks PASS”. If AI helped, complete the AI_Disclosure sheet.

6 The workbook behaves identically in Excel, LibreOffice Calc, and OnlyOffice (dropdowns and formulas included). Spreadsheet interfaces evolve — the sheet names and the yellow-cell rule do not.
