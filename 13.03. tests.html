This Study Hub holds the terms and the reasoning of Class 13: securing wireless networks (WPA2 (Wi-Fi Protected Access 2) and WPA3 (Wi-Fi Protected Access 3), strong passphrases, a separate guest zone), security for virtual platforms and cloud services (shared responsibility, AWS (Amazon Web Services) security groups and Azure NSGs (Network Security Groups), identities), and web application security (injection, cross-site scripting, hardening the service).

Quick pro-tip

Most questions test one idea: encryption protects a link, zoning decides where a device may go, and identities decide what an account may do. When two answers look right, ask which one names the control that actually stops the problem — for example, a parameterized query rather than a WAF (Web Application Firewall) for SQL (Structured Query Language) injection, or a separate VLAN (Virtual Local Area Network) rather than a stronger passphrase for guests.
